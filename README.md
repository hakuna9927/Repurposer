# Traffic Analytics Platform

A simple project scaffold for traffic data exploration and dashboarding.

## Structure

- `data/` - place the Excel dataset here
- `notebooks/` - Jupyter notebooks for analysis
- `powerbi/` - Power BI report files
- `images/` - exported charts and visuals

## Getting Started

1. Create a Python environment.
2. Install dependencies from `requirements.txt`.
3. Open `notebooks/Traffic_EDA.ipynb` and run the analysis cells.
4. Add the dataset file to `data/`.
5. Build the Power BI dashboard in `powerbi/`.

## Notes

The dataset and `.pbix` file are not included in this scaffold.
